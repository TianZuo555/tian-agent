# Agent notes

- Product requirements: `docs/prd.md`; vocabulary: `CONTEXT.md`; decisions: `docs/decisions.md`.
- Package manager: pnpm. Toolchain is pinned in `mise.toml` (Node 26, pnpm 12.5.1); run commands through mise (`mise run verify`) or a mise shell.
- Verify: `mise run verify` = `pnpm typecheck` (tsrs, the Rust port of the TypeScript 7 compiler; `pnpm typecheck:tsc` is the tsc fallback and the two must agree) + `pnpm lint` (oxlint + oxfmt; `pnpm lint:fix` to format) + `pnpm react:doctor` (react-doctor, config in `doctor.config.ts`) + `pnpm test` (builds the service payload, then runs `tests/*.test.ts` with `tsx --test`; no model calls). `mise tasks ls` lists the rest; every task wraps a `package.json` script.
- React Doctor findings: fix the root cause. Suppress a single line with `// react-doctor-disable-next-line <rule>` and a comment explaining why; do not disable whole rules without updating `doctor.config.ts`.
- Local env vars live in git-ignored `.env`, loaded by mise `[env] _.file` (start from `.env.example`). The launchd service cannot see the shell, so `mise run service:env` copies only `MAGPIE_*` / `TELEGRAM_*` into `<dataDir>/service.env` (0600); restart the service afterwards.
- Accessibility: app components in `src/renderer` must pass the oxlint `jsx-a11y` rules (error-level override scoped to `src/renderer/**` in `.oxlintrc.json`; vendored `src/components/ui` is exempt). Every icon-only control carries an accessible name, custom widgets follow the ARIA pattern they claim (roles, roving tabindex, keyboard operation), controls are tied to visible labels via `htmlFor`/`id`, async status changes are announced (`role="status"` / `role="alert"`), decorative icons are `aria-hidden`, and animation honors `prefers-reduced-motion`. Never add the `autoFocus` attribute or `role="application"`.
- Only the resident service writes `tian.db`; schema lives in `src/worker/db.ts`. Feature stores may own their tables in a separate module using `Db.sqlite`, `Db.transaction`, and `Db.once`.
- Chief tools live in `src/worker/tools.ts`; manager (project manager) tools in `src/worker/manager-tools.ts`; worker tools in `src/worker/worker-tools.ts`. Socket/IPC command contracts are in `src/shared/contracts.ts`.
- Docs (README, PRD, decisions) are English-first (default English in root/docs, Chinese versions under docs/); UI copy, code identifiers, and comments are in English.
- UI strings are never hardcoded: they live in `src/renderer/i18n/en.ts` (the key set and English default) with per-locale overrides like `zh.ts` (missing keys fall back to English). Components call `const t = useT()` (subscribes to locale changes); non-component code calls `t()` directly. The choice persists in `localStorage` (`tian.language`) and is switched under Settings → General → Language.
