# 三栏 shell：导航 / 对话 / 上下文

界面定形为三栏：左栏 scope + 会话列表，中栏对话，右栏上下文检查器（Tasks / Runs / Memory / Inbox）。右栏是**常驻且可拖拽调宽、可整体收起**的，而不是弹层抽屉。

## 背景

第一版右栏是固定 320px 的 Tabs 面板，塞了四块内容，视觉上和左栏抢戏；中途试过把 Runs 收进右侧 Drawer，但 Drawer 会盖住对话，验收 diff 时看不到总管的说明，来回开关成本高。用户明确要求回到三栏，并按 Codex / Cursor 的布局来做。

## 决定

- **三栏常驻**，两侧各自可拖拽（`PaneDivider`），宽度写入 `localStorage`。
- **右栏单面板切换**（Codex 式分段 tab），不再四块堆叠：一次只给一种上下文，密度可控。
- **Runs 就地展开**：列表点进 run 详情，diff 用 `@pierre/diffs` 在面板内渲染，Land / Ship / Discard 就在 diff 上方。
- **右栏可整体收起**，收起后留一条 44px 竖条，避免布局跳动。

## 后果

- 对话区宽度会随右栏变化，因此消息容器用 `max-w-3xl` 居中而不是满宽。
- 面板宽度属于本地视图状态，不进 SQLite；换机器不同步，这是有意的。
- 移动端/窄窗口不做适配，`minWidth: 880` 兜住。
