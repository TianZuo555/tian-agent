# 视觉语言：天色

[English](../design-language.md) | **简体中文**

状态：已通过，见 [D23](decisions.md#d23--native-shell-客户端采用天色视觉语言)，2026-11。适用于 Native Shell（NSH）客户端，先做 macOS 和 iOS。可交互的设计稿是 [`docs/design/client-mockup.html`](../design/client-mockup.html)，用浏览器打开。设计稿有四个标签（macOS、iOS、组件、设计说明），可以切换昼夜，全部是示例数据。

Electron 客户端在移除前沿用旧的「墨色单色」语言。旧版本文档在 git 历史 `bb98e08` 中。

## 1. 原则

**一位 Chief，几颗星。** 界面本身是墨色和纸色。颜色和光只属于身份与状态。每个动画都表示一个状态，没有装饰性的动效。

- 对话就是界面。委派、进度、审阅、决定都以卡片出现在对话里。
- Worker 只报阶段，不报日志。原始 CLI 输出不进 UI。
- 产物是一等公民。截图一步发进对话；改动在手机上也能 Land。

## 2. 身份

当前头像采用[动态 SVG 角色](../design/avatars-svg/README.md)：Chief 是光芒与主体分离的太阳；Atlas 是戴眼镜的地球；Juno 是土星；Vega 是戴贝雷帽的条纹行星。两份设计稿共用这些角色。下表记录原始轨道方案；SVG 角色替换其中的图形。25 种表现状态保持各自身份色不变。Worker 卫星和文字状态行保留。表面光照、玻璃和层级遵循第 4 节。

| 角色    | 形状           | 颜色                   | 状态的表示方式                                                                          |
| ------- | -------------- | ---------------------- | --------------------------------------------------------------------------------------- |
| Chief   | 光球           | 黎明渐变（全应用唯一） | 转速和光环：空闲 14 秒一圈；思考 2.6 秒一圈加虚线环；等你时琥珀环；离线时去色并静止     |
| Manager | 带轨道的行星   | 每个项目一种身份色相   | 卫星数等于正在执行的 Run 数。等你：核心脉动。阻塞：色相变珊瑚色，轨道停转。空闲：去饱和 |
| Worker  | Manager 的卫星 | 与 Manager 同色        | Run 执行时出现，结束后消失。没有名字，没有头像                                          |

设计稿中的身份色相：`--atlas #5ee6c9`、`--juno #ffc25c`、`--vega #a99bff`。色相只表示是哪位 Manager，不表示状态；唯一例外是「阻塞」时临时变成珊瑚色。

## 3. 颜色

表面无彩。只有三个色系，另加 diff 的增删行。

| 色系 | Token                                                | 用途                                             |
| ---- | ---------------------------------------------------- | ------------------------------------------------ |
| 黎明 | `--dawn: #ffb86b → #ff6f91 → #8b7cff`（135°）        | Chief 光球、发送按钮、流式光标、焦点环、进度扫光 |
| 身份 | `--atlas`、`--juno`、`--vega`……                      | Manager 行星及其卫星                             |
| 状态 | `--work`（青绿）、`--wait`（琥珀）、`--fail`（珊瑚） | 状态点、光环、横幅                               |
| Diff | `--add`、`--add-bg`、`--del`、`--del-bg`             | 只用于增删行                                     |

两种主题的表面 token：

| Token                  | 夜                                | 昼                                |
| ---------------------- | --------------------------------- | --------------------------------- |
| `--page`               | `#06070b`                         | `#ece8e1`                         |
| `--win`（窗体、玻璃）  | `rgba(14,16,23,.80)`              | `rgba(253,251,247,.82)`           |
| `--card`               | `rgba(255,255,255,.045)`          | `rgba(255,255,255,.78)`           |
| `--line` / `--line-2`  | 白 8% / 15%                       | 墨 9% / 17%                       |
| `--text` / `-2` / `-3` | `#eeece6` / `#a9a8b3` / `#6f6f7d` | `#15161b` / `#5c5d68` / `#9898a3` |
| `--bubble`（你的消息） | `#eeece6` 底，`#111217` 字        | `#15161b` 底，`#f4f2ed` 字        |

规则：

- 一屏最多一个实心反色按钮。黎明渐变只出现在上表列出的位置。
- 成功不用绿色。「完成」用次级文字色加对勾。
- 失败不闪烁。只有「工作中」会动。

## 4. 光影与层级

界面**只有一个光源：Chief**，位于左上，也就是 Chief 在侧栏和手机首页的位置。其他元素只反光，不发光。例外只有状态光和焦点环。

| 层级    | 用途                        | 表面                           | 光                      |
| ------- | --------------------------- | ------------------------------ | ----------------------- |
| L0 天幕 | 桌面、页面底色              | `--wall`：渐变加色斑           | —                       |
| L1 窗体 | 窗口、侧栏                  | `--win`，blur 50，saturate 1.5 | `--rim-strong`          |
| L2 卡片 | 消息卡、列表、设置分组      | `--card`，1px `--line`         | `--rim`，无投影         |
| L3 浮层 | 输入框、菜单、弹出层、toast | `--glass`，blur 24             | `--rim-strong` + `--e3` |
| L4 遮罩 | 截图浮层、sheet、命令面板   | `--glass`，blur 30             | `--rim-strong` + `--e4` |

- **边缘高光**（`--rim`、`--rim-strong`）：顶边 1px 内高光，像光从上方掠过玻璃边缘。夜 `rgba(255,255,255,.07)`；昼 `rgba(255,255,255,.9)`。
- **投影**只给会浮起来的东西（L3、L4）。卡片不加投影。投影背向光源，朝右下。夜里投影是黑色；白天投影带暮紫色（`rgba(60,40,80,.32)`），不用中性灰。
- **环境光**（`--sun`）：Chief 光球在身后的表面投下暖色径向光，半径约 220px，透明度不超过 22%。用在 Chief 行、窗口左上角、手机首页和锁屏。
- **指针光**（`--spot`）：悬停时，一束 280px 的柔光跟随指针。只在有指针的设备上出现。
- **玻璃**：iOS 26 / macOS 26 上，浮动控件用 NSH 的 `glassEffect`（系统 Liquid Glass）；更早的系统退化为背景模糊。内容从下面滚过。
- **玻璃强度**（设置 → 外观）：设为 0 时，所有表面不透明。系统「降低透明度」和低电量模式按同样方式处理。
- 同一屏最多出现三个层级。

## 5. 字体

| 角色         | 字体                                      | 字号                                       |
| ------------ | ----------------------------------------- | ------------------------------------------ |
| 展示         | Instrument Serif；中文用宋体（Songti SC） | 24–64px；问候语、页面标题、Chief 名字      |
| 界面与正文   | Geist；中文用苹方                         | 对话 15px / 1.7（手机 14px），界面 12–14px |
| 数据与元数据 | Geist Mono                                | 9.5–12px；ID、时间、模型、路径             |
| 分组标题     | Geist Mono，大写，字距 `0.12em`           | 10px                                       |

消息正文最宽 720px。对话字号 15px / 1.7 由 D23 确定，取代草案 `docs/spec/ui.md` §11 中的 16px / 1.5。

## 6. 形状

圆角：按钮 10，chip 和胶囊 999，卡片 18，输入框 22，窗口 16，手机 sheet 40。分隔线一律 1px `--line`，不用布局间距假装分隔线。

**选中状态只用底色。** 选中的行（设置导航、改动文件列表、命令面板结果、对话行）使用 `--card` 或 `--card-2` 底色，不加左侧高光条。

| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 侧栏         | 搜索（`⌘K`）；Chief 卡片置顶，带环境光；每位 Manager 一行：行星、名字、项目、presence 行。进行中的 Run 以迷你轨道挂在 Manager 下面。底部：服务器状态和设置齿轮。                                             |

| 委派卡       | Chief 光球 → Manager 行星、任务标题、附件、「打开 Manager」。                                                                                                                                                |
| 进度卡       | 每个 Run 一张，原地更新：轨道上的四个阶段（理解、修改、验证、汇报）、一句话、用时、改动统计、顶部 2px 扫光。「经过」展开后最多 8 条里程碑。                                                                  |

| 审批卡       | 琥珀色底纹、准确的操作、带后果说明的单选项、批准 / 再问问 / 拒绝。拒绝后同一操作不能再执行。                                                                                                                 |
| 工具活动     | Chief 和 Manager 的工具调用按轮折叠；默认收起，出错时自动展开。Worker 的工具调用不出现在这里。                                                                                                               |
| 思考         | 思考时显示带扫光的「思考中 · 4 秒」；结束后折叠成一行，放在答案上方。                                                                                                                                        |
| 通知卡       | 严重程度图标、关联对象、已处理 / 忽略 / 打开。                                                                                                                                                               |
| 记忆候选     | 陈述、类型、scope、证据原文；确认 / 确认并选入 Core / 修订 / 驳回。                                                                                                                                          |
| 错误         | 珊瑚色描边。不替换上一条完好的消息。重试复用同一个 `requestId`。                                                                                                                                             |

| 截图         | macOS：`⌥⇧S` 打开系统框选，然后弹出 L4 浮层：选发给谁（Chief 或某位 Manager）、可选的一句话、回车发送。输入框上方提示 5 分钟内的「刚截的图」，点「附加」后才上传。iOS：分享面板「发给 Tian」，问同样两件事。 |

| 弹出层       | 模型选择（模型列表 + 思考强度，「只改这个对话」）；命令面板（`⌘K`，分组结果，匹配文字用黎明粉下划线）。                                                                                                      |
| 通知与 toast | 等你、失败、完成时发系统通知。toast 只用于你刚做的动作。                                                                                                                                                     |
| 连接状态     | 同步中：顶栏下 2px 黎明扫光。重连中：琥珀横幅，写上次同步时间。离线：珊瑚横幅，写节点名。冷启动：形状与内容一致的骨架；内容上方不放转圈。                                                                    |
| 设置         | 见第 9 节。                                                                                                                                                                                                  |
| 锁屏（v2）   | iOS Live Activity：正在执行的 Run、阶段轨道和用时。                                                                                                                                                          |

## 8. Worker 阶段

服务端用固定规则从 Worker 的工具调用推出阶段，不调用模型。客户端只收到阶段、一句话、用时和改动统计。

| 阶段 | 工具调用                               |
| ---- | -------------------------------------- |
| 理解 | `read`、`grep`、`find`、`ls`           |
| 修改 | `edit`、`write`、补丁类工具            |
| 验证 | `bash` 中的 test、lint、typecheck 命令 |
| 汇报 | 写 Run 报告；Attempt 结束              |

阶段可以回退（测试失败后回到「修改」）。「等你输入」和「失败」会通知你；「工作中」从不通知。

## 9. 设置

macOS：从齿轮或 `⌘,` 打开，盖住整个窗口；`Esc` 关闭并回到原来的界面。iPhone：分组列表。分组名写明每项设置归谁所有。

| 分组   | 归属               | 页面                                 |
| ------ | ------------------ | ------------------------------------ |
| 智能体 | 账号，所有设备共享 | 模型、提供方、Worker 与 Intent、技能 |
| 个人   | 只在这台设备       | 通用、外观、截图、通知               |
| 运行   | 服务器             | 服务器与设备、渠道、用量、改进日志   |

- 外观页放光影相关的开关：主题（跟随系统 / 夜 / 昼）、玻璃强度、指针光、Chief 环境光、减少动效、对话字号、代码换行。
- 截图页放所有截图入口：快捷键、「刚截的图」提示及其时间窗口、默认发送对象、上传前缩小（长边 2560px）、系统权限状态。
- 通知按状态分别开关；「工作中」固定关闭。Chief 主动消息有三档：关、少、多。
- 服务器与设备页列出已配对的设备，可以逐台撤销；显示本机缓存大小，可以清除。
- 提供方的密钥存在服务器上，客户端只显示末尾几位。

## 10. 动效

| 动效                  | 取值                              |
| --------------------- | --------------------------------- |
| 光球自转              | 空闲 14 秒；思考 2.6 秒           |
| 光环呼吸              | 4.2 秒；思考或等你时 1.6–1.8 秒   |
| 状态 ping（`--work`） | 2 秒                              |
| 进度扫光              | 2.4 秒，线性                      |
| 卫星公转              | 7 秒，线性                        |
| 消息出现              | 360ms：透明度、上移 8px、模糊 2px |
| 浮层与设置进入        | 240–300ms                         |
| 检查器开合            | 320ms 列宽过渡                    |
| 缓动                  | `cubic-bezier(0.22, 1, 0.36, 1)`  |

开启减少动效时，所有动画停止，状态只用颜色表示。不用回弹，不用视差，进入动画不超过 400ms，动效不得阻塞输入。

## 12. 图标与无障碍

- 图标仍然只用 Phosphor。设计稿里画的是简化的替身。
- 每个只有图标的控件都有无障碍名称。装饰性图形（光球、行星）设为 `aria-hidden`；它们表示的状态也写在 presence 行里。
- 状态变化每秒最多播报一次；不朗读整段流式正文。
- 界面文字放在 `src/renderer/i18n/en.ts`，中文覆盖在 `zh.ts`。设计稿里的中文文案是 zh 语言的示例。

## 13. 不要这样做

- 不要第二种渐变。除了 Chief 光球和状态光，不要霓虹光晕。
- 不要给卡片加投影。不要让投影朝向光源。
- 不要用左侧高光条表示选中。
- 不要用颜色做装饰：每个色相都表示身份、状态或 diff。
- 不要在 UI 里显示 Worker 的原始输出；macOS 上不要把 diff 放进模态框。
- 不要做不表示状态的动画。
