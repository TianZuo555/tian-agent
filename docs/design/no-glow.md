# No-glow colour study

Open [client-mockup-no-glow.html](client-mockup-no-glow.html) for the no-glow variant. [client-mockup.html](client-mockup.html) is the original design. The variant is a separate, self-contained HTML file with the same sample conversations and interactions.

The variant uses solid charcoal surfaces at night and warm paper surfaces by day. It removes background colour pools, ambient light, pointer spotlights, avatar glow, and coloured shadows. The Chief keeps the gradient inside its shape. Manager cores use flat identity colours. Status and keyboard focus use crisp outlines. Working dots change opacity without an expanding halo.

Cards use borders without highlights or shadows. Floating controls use short neutral shadows. The window is opaque, so the glass-strength slider is disabled. The Components tab shows the no-glow surface samples. The original lighting experiments are hidden; the Design notes tab states which original rules this study replaces.

| Surface | Night     | Day       |
| ------- | --------- | --------- |
| Page    | `#111113` | `#f4f3ef` |
| Desktop | `#1c1c1f` | `#e6e5e1` |
| Window  | `#18181b` | `#faf9f6` |
| Card    | `#202023` | `#ffffff` |
| Border  | `#303034` | `#ddddd7` |

This is a visual proposal. It does not change the accepted design language or the application.
