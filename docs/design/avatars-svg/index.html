思考

完整状态表

每一种状态都适用于太阳和全部行星。点击任一状态，上方角色同步变化。

颜色属于身份

主色驱动本体、地表纹理、条纹和星环。状态通过表情和符号表达，失败也不会把整颗行星染红。

动作有节制

等待和失败不反复跳动。完成只轻跳一次。减少动效时保留表情和状态符号，也会遵循系统设置。
