# Fonts

The demo uses three families, downloaded from Google Fonts and shipped with the
app so the page needs no network at run time.

| File                                                                     | Family           | Weights | License            |
| ------------------------------------------------------------------------ | ---------------- | ------- | ------------------ |
| `Geist-400.ttf` to `Geist-700.ttf`                                       | Geist            | 400–700 | SIL OFL 1.1        |
| `GeistMono-400.ttf`, `GeistMono-500.ttf`                                 | Geist Mono       | 400, 500 | SIL OFL 1.1        |
| `InstrumentSerif-400.ttf`, `InstrumentSerif-400i.ttf`                    | Instrument Serif | 400, italic | SIL OFL 1.1    |

Source: <https://fonts.google.com/specimen/Geist>,
<https://fonts.google.com/specimen/Geist+Mono>,
<https://fonts.google.com/specimen/Instrument+Serif>.

Chinese text falls back to the system serif and sans families the styles name
(`PingFang SC`, `Songti SC`), as the mockups do.

The SIL Open Font License 1.1 permits bundling and redistribution with the
fonts' copyright notices. Keep this file with the font files.
