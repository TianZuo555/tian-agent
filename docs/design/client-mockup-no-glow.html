          设计说明 · v0.2
          

            当前为无光晕配色提案：去掉背景色斑、环境光、指针光、头像外发光和彩色投影。
            保留图形内部的渐变、身份色、状态色和焦点描边。下方光影说明为原版参考；本版以此处规则为准。
            顶栏「查看原版」可打开原始设计稿。
          

          
天色：一位 Chief，几颗星。

          

            客户端只做一件事：让你和 Chief 对话，并在需要时和某个 Manager
            对话。Worker 是 Manager 的卫星。你看得到它在转，看不到它的日志。
          


          
角色的样子 identity

          

            

              Chief · 光球
              

                唯一的彩色渐变。转速表示状态：慢转是空闲，快转加虚线光环是思考或工作，琥珀色光环是等你。
              

            

            

              Manager · 行星
              

                每个项目一种色相。名字在注册项目时给出。颜色只用于身份，不用于状态。
              

            

            

              Worker · 卫星
              

                没有名字，没有头像。卫星数等于正在跑的 Run 数。卫星停下，表示
                Run 结束。
              

            

          


          
三条原则 principles

          

            

              一对话就是界面
              

                委派、进度、审阅、决定都以卡片出现在对话里。没有独立的仪表盘页面。
              

            

            

              二只报阶段，不报日志
              

                Worker 的输出由服务端压缩成四个阶段和一句话。原始流不进 UI。
              

            

            

              三产物是一等公民
              

                截图和改动都可以直接操作：截图一步发出，改动在手机上也能 Land。
