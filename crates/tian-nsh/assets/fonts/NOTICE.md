(https://github.com/vercel/geist-font). Phosphor: Copyright (c) 2020-2021
Phosphor Icons.

The text fonts are latin subsets, so Chinese text falls back to the system's
CJK font (PingFang SC on macOS). The Phosphor file is the regular icon font; the
app maps the glyphs it uses in `icons.ts`.
